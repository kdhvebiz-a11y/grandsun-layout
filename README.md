# 그랜드썬 태양광 배치·제안서 작성기

지도에서 건물·토지·주차장을 골라 사내 설치기준대로 모듈을 배치하고 견적·수익성·제안서(PPT)를 만드는 사이트.

- 로컬: `서버실행.bat` → http://localhost:8080/배치도/ (건축물대장 조회·제안서 양식 자동 로드 포함)
- 웹: GitHub Pages (제안서 양식은 「양식 직접 선택」으로 pptx 를 고름, 건축물대장은 중계 서버 필요)
- API 키: `keys.js` (카카오·브이월드·구글은 도메인 제한), 공공데이터포털 키는 `datago.txt`(깃 제외)
